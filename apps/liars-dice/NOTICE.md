# NOTICE · Liar's Dice / 吹牛骰

Liar's Dice is an original, non-commercial family game made for Family Arcade.
The bluffing-dice folk game is public domain; this implementation, its name,
copy, visual design, engine, AI and code are original.

- No third-party art, card text, dice art, font files or audio samples are
  included. All dice, cups, pips, icons and the table are drawn in CSS/SVG for
  this project.
- Sound is synthesised with the Web Audio API from scratch. There are no
  downloaded samples.
- No CDN, remote font or network asset is loaded by the app.
- Code and original assets are MIT. See [LICENSE](LICENSE).
- The shared LAN transport is the repository's own `@family-arcade/lan` package
  and `family_arcade_lan_host` Tauri crate.

  owners.
