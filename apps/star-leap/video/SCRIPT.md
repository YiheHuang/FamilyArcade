# Star Leap promo — two cuts · 48 s · 1920×1080 · 60 fps

A quiet, typographic promo for the family Chinese Checkers app: paper, a midnight
star board and ten glass marbles, with a real 64-move AI game and a short narration in
Chinese and English. Built with Remotion following the official
`remotion-best-practices` skill (`remotion-skills/skills/remotion-best-practices`).

- **Duration** 48.0 s · 2880 frames each
- **Format** 1920×1080, 60 fps, H.264/AAC, yuv420p
- **Cuts** `StarLeapPromoZH` (中文) and `StarLeapPromoEN` (English)
- **Sound** generated score from the Blokus family project + seven narration lines +
  board/card SFX
- **Accuracy** every number/rule comes from the app: [`FACTS.md`](FACTS.md)

## Design language

- Paper `#f7f3ea`, ink `#1d2430`, accent brass `#b08a4f`, line `#ddd3c3`
- Board: midnight `#172233` with brass holes; marbles use the app’s four player
  colours and colour-blind marks (dot / plus / ring / slash)
- Type: serif headlines (Iowan/Palatino/Noto Serif SC/SimSun), sans body
  (Avenir/Segoe/Noto Sans SC/Microsoft YaHei)
- Motion: `useCurrentFrame()` + `interpolate()` only; hard cuts; slow-out; no CSS
  transitions
- Safe area 120 px sides / 80 px top-bottom; subtitles below y = 960

## Audio

- **Score** — generated 48 s, 80 BPM family score from the Blokus project; low under
  voice.
- **Narration** — seven lines per language, generated by `scripts/gen-voice.mjs`.
- **SFX** — board tick at title, placement at the game cut, tick at modes, chime at
  the end.
- **Subtitles** — burned in from `src/data/narration.{zh,en}.json`; SRT sidecars in
  `../docs/promo/`.

## Build

```bash
cd video
npm install
npm run gen        # real game data + voice + SRT
npm run facts      # accuracy gate -> FACTS.md
npx remotion studio
npm run render     # out/star-leap-promo-zh.mp4
npm run render:en  # out/star-leap-promo-en.mp4
npm run master     # loudness master + posters -> ../docs/promo
# or: npm run release
```

`scripts/master.mjs` applies the measured gain/limiter (+6.0 dB Chinese, +4.0 dB
English, limiter −1.6 dBTP) and extracts the posters at 5.4 s. The app screenshots are
generated by `../scripts/shots.mjs` from the real Vite app.

## Why each claim is true

See [`FACTS.md`](FACTS.md). In short:

- 121 holes, six 10-hole triangles, ten marbles, 2–4 players, four AI levels: the real
  TypeScript board/engine/types.
- The 64-move game is generated by the real engine and replayed by `replay()`.
- UI stills are captured from the real app with Playwright.
- “Offline, no account, no ads” is true of the v0.1 browser app.
- No LAN/desktop claim is made in this cut.
