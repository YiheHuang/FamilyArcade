# NOTICE · Texas Hold'em / 德州扑克

Texas Hold'em is an original, non-commercial family game made for Family Arcade.
The rules of Texas Hold'em are a public-domain card game; this implementation,
its name, copy, visual design, card art, table and code are original.

- No third-party art, card text, font files, audio samples or remote assets are
  included.
- Every card, chip, table, icon and background is drawn in CSS for this project.
- Sound effects are synthesised with the Web Audio API from scratch.
- Play money only. Chips have no cash value and there is no cashier, wagering
  market, odds service or real-money feature.
