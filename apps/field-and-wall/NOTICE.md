# NOTICE — Field & Wall · 筑野

Field & Wall is an **independent, non-commercial family project**. It is not affiliated
with, endorsed by, sponsored by, or derived from *Carcassonne* or any game publisher.

## Original expression

- The name **Field & Wall / 筑野**, the 54-tile set, the 15 tile types, the scoring table,
  the five-line rules summary, the UI copy and the tutorial are original to this project.
- All tile, board, meeple and icon artwork is drawn in code (SVG/CSS) for this project.
  No third-party card art, tile art, rulebook text or board scan is included.
- The promo film and posters are built with Remotion from this project's real screenshots,
  engine data and code-drawn art.
- Music and sound effects are synthesised by scripts in this repository. No third-party
  samples are included.
- Promo voiceover is generated with Microsoft Edge TTS
  (`zh-CN-YunxiNeural`, `en-US-AndrewNeural`) for this project's own script.
- Fonts are the system UI fonts (Iowan Old Style / Palatino / Noto Serif SC / Songti SC /
  Segoe UI / PingFang SC etc.); no remote font is downloaded.

## Mechanic attribution

Tile-laying with edge matching and follower placement is a traditional tabletop mechanic.
This project borrows the **mechanic**, not any protected expression. *Carcassonne* is a
trademark of its respective owner (Hans im Glück / Z-Man Games); its name, tile designs,
art and rulebook text are not used here. If you enjoy this family game, please also
support the original published game.

## Data & privacy

- No account, no telemetry, no ads, no internet service.
- LAN play uses a WebSocket to the bundled relay on the same local network only.
- Settings, saves and stats use this browser's `localStorage`.
- The promo screenshots contain only locally seeded demo names and scores.
