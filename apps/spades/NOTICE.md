# NOTICE · Spades / 黑桃皇后

Spades is an original, non-commercial family game made for Family Arcade. The
four-player partnership trick-taking rules are public-domain card-game rules; this
implementation, its name, copy, visual design and code are original.

- No third-party art, card text, font files or audio samples are included.
- Every card face, card back, table, seat, app icon and UI icon is drawn in CSS and
  inline SVG.
- Sound is synthesised at runtime with the Web Audio API; there are no sample files.
- The promo narration, when rendered by the root studio, is synthetic; no third-party
  music or voice samples are included.
