# NOTICE · Mill / 九子棋

Mill is an original implementation of Nine Men's Morris, a traditional
public-domain board game. The 24-point board, nine-men setup, mill capture and
movement rules are part of the public domain; this implementation, its name, copy,
visual design, tests and code are original work for Family Arcade.

- No third-party art, board textures, font files, audio samples or card text are
  included.
- Every stone, line, frame, icon and page texture is drawn with CSS or inline SVG.
- Sound effects are synthesised at runtime with Web Audio oscillators.
- Screenshots are captured from the running application with Playwright. Some
  late-game and record states are seeded through the app's real autosave JSON and
  then played through the UI.
