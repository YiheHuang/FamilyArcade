# NOTICE · Hearts / 红心大战

Hearts is an original, non-commercial family game made for Family Arcade. The
four-player Hearts rules are a public-domain folk card game; this implementation, its
name, copy, visual design, code and generated screenshots are original to this project.

- No third-party art, card scans, font files, audio samples or remote assets are used.
- Every card, table, icon and animation is drawn with CSS and Unicode card suits.
- Sounds are synthesised at runtime with the Web Audio API.
- The 45-second promo is rendered by the shared Family Arcade studio from `video.json`;
  narration there is synthetic.
