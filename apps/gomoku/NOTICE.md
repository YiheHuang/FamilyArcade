# NOTICE · Gomoku / 五子棋

Gomoku is an original, non-commercial family game made for Family Arcade. The
15×15 freestyle five-in-a-row mechanic is a public-domain folk game; this
implementation, its name, copy, visual design and code are original.

- No third-party art, font files or audio samples are included.
- All stones, board texture, marks and icons are drawn in CSS for this project.
- Sounds are synthesised locally with the Web Audio API.
