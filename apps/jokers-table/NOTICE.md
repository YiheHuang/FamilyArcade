# NOTICE · Joker's Table / 小丑牌桌

Joker's Table is an original, non-commercial family game made for Family Arcade.
The poker-hand ranking used by card games is public-domain game knowledge; this
implementation, its 24 jokers, 8 bosses, 4 decks, 6 enhancements, 4 vouchers, names,
copy, balance, visual language and code are original.

- No commercial roguelike-deckbuilder assets, joker names, boss names, deck names,
  art, UI layout, copied visual style, music or text are used.
- No other commercial card game's art or text is included.
- Every card face, card back, table, joker glyph, ornament and favicon is drawn in
  CSS or inline SVG.
- Sound is synthesised at runtime with the Web Audio API; there are no sample files.
- No remote fonts, CDN links, downloaded images or third-party audio samples are
  loaded.
- The promo narration, when rendered by the root studio, is synthetic; no third-party
