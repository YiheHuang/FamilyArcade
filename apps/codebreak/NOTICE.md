# NOTICE · Codebreak / 猜色

Codebreak is an original, non-commercial family game made for Family Arcade. The
public-domain peg code-breaking mechanic (four hidden colours, black/white
clues, a limited number of guesses) is a folk game tradition. This
implementation, its name, copy, visual design, AI code and engine are original.
