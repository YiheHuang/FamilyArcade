# Blokus promo

A 48-second, 1920x1080, 60 fps promo for the Blokus family app, built with
Remotion — **two cuts**: Chinese (`BlokusPromoZH`) and English
(`BlokusPromoEN`). The board, pieces, colours and scores come from the real game
engine in `../src`, so the video cannot drift from the app. Score and narration
are generated by scripts in `scripts/`.

- Storyboard, copy and build steps: [`SCRIPT.md`](./SCRIPT.md)
- Every on-screen claim and its automated check: [`FACTS.md`](./FACTS.md)
- Outputs: `out/blokus-promo-zh.mp4` and `out/blokus-promo-en.mp4`
  (48.0 s, H.264/AAC, yuv420p)

```bash
npm install
npm run gen      # real game data + synthetic score + SFX + font subsets
npm run voice    # both narrations
npm run facts    # accuracy gate
npm run stills   # key frames -> out/stills/ (COMP=BlokusPromoEN for English)
npm run render   # out/blokus-promo-zh.mp4
npm run render:en
```
