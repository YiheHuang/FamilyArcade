# Blokus v1.3.0

**Replay the turning point, and see who is really winning.** Every game is now kept, and the family stats page tracks the bragging rights.

## What's new

- **Replay**: when a game ends, tap **Replay** to step through it move by move (or hit play). The board, the move number and the running score are all there — perfect for settling "wait, why did I do that?" — or for showing off a perfect finish.
- **Game records**: the last ten finished games are stored on your device, with the full move history.
- **Stats screen** (from the home page): games played per mode, wins, win rate, best score, current streak for every player name — plus the family's favourite colour.
- Clear all records whenever you like; nothing ever leaves your machine.

## Install

Download `Blokus_1.3.0_x64-setup.exe` below and run it — per-user install, no admin required. Your settings and stats stay.

The release page shows the SHA‑256 digest of the uploaded installer under *Assets*.
