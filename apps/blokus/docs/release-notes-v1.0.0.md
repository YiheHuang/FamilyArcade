# Blokus v1.0.0

First family release — a small, fast, offline Blokus for game night.

## Highlights

- **Solo practice** against three AI levels (Beginner / Intermediate / Expert) with hints and undo
- **Hot-seat** for 2–4 players sharing one screen
- **LAN play**: one machine hosts, everyone else joins from a browser — no install needed on their side.
  Seats survive disconnects, and if a player drops for more than ~12 seconds the host's AI caretaker
  plays on so the table never stalls
- Standard 20×20 (2–4 players) and faster Duo 14×14 boards
- Drag a piece, spin it with the rotation ring, right-drag to flip, click the board to confirm
- Color-blind friendly: every player has a colour **and** a mark (dot / plus / ring / slash)
- English and Chinese; follows your system language, with a manual toggle on the home screen
- Fully offline, no accounts, no telemetry

## Install

1. Download `Blokus_1.0.0_x64-setup.exe` below and run it — per-user install, no admin required.
2. Windows 10/11 (x64). Uses the system WebView2 runtime (preinstalled on current Windows).
3. Hosting a LAN room for the first time? Allow the Windows Firewall prompt (TCP 7667, UDP 7668).

## Size

- Installer: ~1.4 MB
- Installed app: one ~3.6 MB executable (plus your settings)
