# Blokus v1.2.0

**Everybody plays on their phone.** The browser version now gets the same care as the desktop app, because that is where family players actually sit.

## What's new

- **Phone layout**: the board fills the screen, the piece tray turns into a swipeable strip with bigger pieces, action buttons grow to comfortable touch sizes, and the score list becomes a compact two-line summary.
- **Touch-first controls**: pull a piece out of the tray with a short upward swipe and drag it onto the board; the rotation ring works with a finger, two-finger rotation still works, and a tap on the board confirms the placement. Pinch-zoom/scroll no longer fights your drags.
- **Joining from a phone is unchanged**: open the invite address, pick a name, play.

Existing installations are not affected; guests always get the newest UI straight from the host.

## Install

Download `Blokus_1.2.0_x64-setup.exe` below and run it — per-user install, no admin required. Your settings and stats stay.

The release page shows the SHA‑256 digest of the uploaded installer under *Assets*.
