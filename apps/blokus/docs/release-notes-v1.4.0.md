# Blokus v1.4.0

**The table manners update.** Undo requests, pause for dinner, nudge the slow one — and let the grandparents watch from their own screens.

## What's new

- **Undo, with everyone's blessing**: ask to take back your last move and everyone at the table gets a small vote card. All agree → the board rolls back to just before your move and every device syncs. One "no" → nothing happens. (The requester can cancel; 60 seconds without an answer counts as cancelled.)
- **Pause / resume** (host): freeze the whole table for dinner or homework — every screen shows "Paused" until the host resumes.
- **Nudge**: one tap sends "Sarah is waiting for you" to the table — a reminder, never a penalty.
- **Watch mode**: a fifth (or sixth…) person can join mid-game as a spectator. They see the live board, the scores and every move — but cannot touch anything. Perfect for the audience that gathers around a good game.

Everything stays on the local network; the host remains the only authority.

## Install

Download `Blokus_1.4.0_x64-setup.exe` below and run it — per-user install, no admin required. Your settings, stats and replays stay.

The release page shows the SHA‑256 digest of the uploaded installer under *Assets*.
