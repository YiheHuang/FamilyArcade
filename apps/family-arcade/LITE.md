# Family Arcade Lite

A very small launcher that installs only the games you want.

- The installer contains the launcher and the catalog, not the games.
- The installer uses Tauri's WebView2 bootstrapper: if WebView2 is missing, it is
  checked and installed before the launcher opens. Game downloads start afterwards.
- Each game downloads as a portable ZIP (about 4–7 MB).
- Installed games live under `%LOCALAPPDATA%\com.familyarcade.lite\games`.
- Use **Settings → Installed games** to remove a game or check disk use.
- The **Offline** and **Slim** all-in-one installers remain available if you want
  everything at once.

## Private downloads

The game packages are attached to a private GitHub release. Lite needs a read-only
GitHub token once per device:

1. Open GitHub → Settings → Developer settings → Personal access tokens →
   **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `YiheHuang/FamilyArcade`.
3. Repository permissions: **Contents: Read-only** and **Metadata: Read-only**.
4. Generate the token and paste it into **Lite → Settings → GitHub download key**.

The token is stored locally in the app config folder and is only used to read release
assets. Revoke it on GitHub if a device is lost. If the release assets are ever made
public, Lite works without a token.

## Build

```bash
npm install
npm run build:lite
npx tauri build --features lite --bundles nsis \
  --config src-tauri/tauri.lite.conf.json
```

The catalog is generated by `node tools/build-lite-packages.mjs` after
`node tools/prepare-hub.mjs` has assembled the portable game folders.
