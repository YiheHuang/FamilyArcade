# NOTICE · Hex / 六角棋

Hex is an original, non-commercial family game made for Family Arcade. The connection
game itself is public domain: Piet Hein described it in 1942 and John Nash
independently invented it in 1947. This implementation, its name, copy, visual
design, code and board art are original to Family Arcade.

- No third-party art, card text, font files or audio samples are included.
- The board, stones, edge marks and favicon are drawn with CSS, HTML and inline SVG.
- Sound effects are synthesised in the browser with the Web Audio API.
- Background music or narration used by the promo, if any, is generated by the root
  Family Arcade studio; this app ships none.
