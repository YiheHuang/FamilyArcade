# NOTICE · Mini Chess / 迷你棋

Mini Chess is an original 5×6 chess variant made for Family Arcade. The variant name,
starting array, rules text, visual design, copy and code are original to this
project. Chess itself is a public-domain folk game; no third-party chess
implementation, opening book, engine, art or font file is included.

- No third-party art, card text, font files, music or audio samples are bundled.
- The board, layout, icons and CSS are drawn in this repository.
- Chess piece shapes are Unicode characters rendered by the operating system
  (`Segoe UI Symbol` / Noto / DejaVu fallbacks). They are not copied assets.
- The LAN relay and Tauri shell are shared Family Arcade code under
  `packages/lan` and `crates/lan-host`.
- The promo manifest is rendered by the root Family Arcade studio; any narration or
  music it produces is synthesised there, not shipped inside this app.
