# NOTICE · International Draughts / 国际跳棋

International Draughts is a public-domain board game. This implementation, its
name treatment, copy, visual design, code and interface are original work for
Family Arcade.

- No third-party art, piece sets, board textures, font files or audio samples
  are included.
- The board, discs, crowns, icons and interface are drawn in CSS and inline SVG.
- Sound is synthesised from scratch in the browser with the Web Audio API.
- Narration for the promo is synthetic Edge TTS and is rendered from
  `video.json` by the root studio; no third-party samples are used.
