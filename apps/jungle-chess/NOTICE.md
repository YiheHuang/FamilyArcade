# NOTICE · Jungle Chess / 斗兽棋

Jungle Chess (Dou Shou Qi) is a traditional public-domain folk game. This Family Arcade
implementation — its engine, name, copy, visual design and code — is original.

- No third-party art, card text, font files or audio samples are included.
- The board, rivers, traps, dens and UI are drawn in CSS and inline SVG.
- Animal tokens use the operating system's standard emoji glyphs; no image files or
  external fonts are downloaded.
- Sounds in the app are synthesised with the Web Audio API.
- Promo narration is synthetic Edge TTS generated from the text in `video.json`.
