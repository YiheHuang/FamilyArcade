# NOTICE · Sowing / 播棋

Sowing is an original, non-commercial family game made for Family Arcade. Mancala (Kalah)
is a public-domain folk game; this implementation, its name, copy, visual design and
code are original.

- No third-party art, card text, font files or audio samples are included.
- The board, bowls, seeds and icons are drawn in CSS and inline SVG for this project.
- Sounds are synthesised in the browser with the Web Audio API. The promo, when rendered,
  uses synthesised music and synthetic narration created by the root studio.
