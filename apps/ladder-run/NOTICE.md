# NOTICE · Ladder Run / 蛇梯棋

Ladder Run is an original, non-commercial family game made for Family Arcade. Snakes and
ladders / 蛇梯棋 is a public-domain folk game; this implementation, its name, copy,
visual design and code are original.

- No third-party art, card text, font files or audio samples are included.
- The board, ladders, snakes, tokens, dice pips and icons are drawn in CSS/SVG for this
  project. The UI uses system fonts only.
- Sound is synthesised at runtime with the Web Audio API; there is no bundled music or
  sample library.
- Runtime dependencies are React, `@tauri-apps/api`, `qrcode` and the shared
  `@family-arcade/lan` package. They remain under their respective open-source licences.
- The promo is represented by `video.json`; the root Family Arcade studio renders it. No
