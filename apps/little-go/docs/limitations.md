# Little Go · known limitations (v0.1)

- **Simple scoring only.** The game uses stones on the board plus fully surrounded
  empty points. It does not ask players to mark dead stones, does not remove dead
  stones, and does not require dame to be filled. A dead stone left on the board
  therefore still counts. This is the “simple territory scoring” named in the brief.
- **Simple ko only.** Immediate single-stone recapture is blocked. There is no
  superko, triple-ko or positional-repeat rule.
- **No resignation, handicap or clocks.** Games end with two consecutive passes.
  Komi is fixed at 6.5; there is no bidding or rule-set choice.
- **Suicide is forbidden.** A move that leaves its own group with no liberties is
  rejected (unless it captures first).
- **The AI is heuristic.** Companion, Easy, Normal and Hard share a liberty/atari/
  influence shortlist. Normal uses 30 random playouts and Hard uses 200. Hard is a
  good family challenge, not a dan-level opponent, and random playouts are noisy.
- **Companion is gentle, not a teacher.** It avoids filling eyes and avoids big
  captures, so it can leave good moves on the table. That is intentional for
  children, but it is not a Go tutor.
- **LAN is local-subnet IPv4.** The Tauri build or `npm run lan` hosts a relay on
  port 8080. Guests need the host’s firewall to allow the app. There is no cloud,
  matchmaking, spectator seat or reconnect lobby UI beyond the shared `@family-arcade/lan`
  token handling.
- **LAN games are not added to the local family record.** The record belongs to
  the device that finished a local/AI game; the host keeps the LAN board.
- **Installer is unsigned.** The Tauri NSIS build is a local family build and may
  trigger Windows SmartScreen. It has not been built in this workspace.
- **No separate promo render in this app.** `video.json` is the manifest; the root
  studio renders the 45-second EN/ZH promo. This app ships neither a Remotion
  project nor a downloaded video.
- **Screenshots are real.** They are captured by `scripts/shots.mjs` at 1440×1000
  and 780×1688 (390×844 @2×). The finished positions are replayed from a legal game
  generated by the app’s own engine.
