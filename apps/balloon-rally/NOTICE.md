**Balloon Rally · 气球大赛** is an original, non-official, non-commercial family game project.

- Game rules implementation, engine, AI, UI copy, SVG balloon and valley art, interface design, screenshots, data, and synthesized audio were created for this project.

## Assets

- Balloon, track, wind-card, and interface graphics are original SVG drawn in code.
- Screenshots in `docs/screenshots/` and `docs/promo/` are captured from the running application.
- Fonts are system font stacks; no font files are redistributed.
- Audio in `video/public/audio/` is generated by `video/scripts/gen-audio.mjs` (original procedural tones/noise). Narration MP3s are synthesized with Microsoft Edge TTS (Aria/Xiaoxiao) from the project's own script; they are not recordings of a real person.
- The Remotion promo uses screenshots from this app and engine-generated game data.

## Family-safe language

The game uses **support / back / tailwind / wind** vocabulary. It does not use real currency, accounts, loot boxes, daily streaks, or purchases. The UI and bilingual dictionary are checked by tests for the specific vocabulary listed in `tests/data.test.ts`.

## Privacy

The app has no network requests, no accounts, no analytics, and no telemetry. Settings, stats, and the current save live in the browser's `localStorage` and can be cleared from Settings or site data.

## Contact / project status

This is a private family project. v0.1 is a browser build; LAN and a Windows installer are next milestone and are not claimed as available.
