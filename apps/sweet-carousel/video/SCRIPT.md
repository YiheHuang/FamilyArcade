## Narration and audio

- **EN voice:** Edge TTS `en-US-AvaNeural`, rate −6%, one clip per line, `video/public/audio/voice/en/line-1..9.mp3`.
- **ZH voice:** Edge TTS `zh-CN-XiaoxiaoNeural`, rate −6%, one clip per line, `video/public/audio/voice/zh/line-1..9.mp3`.
- **Music:** original 49 s synth bed generated by `video/scripts/gen-music.mjs` (no samples, no third-party music), `video/public/audio/bgm.wav`.
- **Mix:** BGM drops from 0.16 to 0.06 under a voice line; voice at 1.0. Mastered with `loudnorm=I=-14:TP=-1.5:LRA=11` + limiter in `video/scripts/master.mjs`.
- **Measured:** EN −14.1 LUFS / −1.0 dBTP; ZH −14.1 LUFS / −1.5 dBTP.
- **Subtitles:** burned in by `video/src/Subtitles.tsx`, plus external SRTs in `docs/promo/*.srt`. The SRT text is generated from the same narration JSON.

## Build and render

```bash
cd video
npm install
npm run gen:data     # real engine demo JSON for EN/ZH
npm run gen:music    # original synth bed
npm run gen:voice    # Edge TTS clips + measured narration JSON
npm run gen:srt      # docs/promo/*.srt
npm run dev          # Remotion Studio
npm run render       # EN MP4 to video/out/
npm run render:zh    # ZH MP4 to video/out/
npm run master       # loudnorm + limiter + yuv420p/bt709 to docs/promo/
node scripts/facts.mjs
```

- The video is **Remotion only**. All motion uses `useCurrentFrame()` with `interpolate()` / `spring()`; no CSS transitions or animations.
- Images use `<Img src={staticFile(...)}>`; audio uses `<Audio>` from `@remotion/media`; scenes use `<Sequence premountFor={30}>`; compositions are registered with `<Composition>`.
- The archival end card says **Web v0.1 · LAN and installer are next milestone** because that is what was true when the cut was rendered. The current app ships LAN; the cut is kept unchanged for provenance.
