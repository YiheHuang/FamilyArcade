## Regenerate

Requirements: Node 22+, Python with `edge_tts`, ffmpeg/ffprobe, and a Chrome/Chromium for Remotion. Run from `video/`:

```bash
npm install
npm run gen:data
npm run gen:music
npm run gen:voice
npm run gen:srt
npm run dev          # Remotion Studio
npm run render       # EN raw -> out/sweet-carousel-promo-en.mp4
npm run render:zh    # ZH raw -> out/sweet-carousel-promo-zh.mp4
npm run master       # master both to ../docs/promo/
node scripts/facts.mjs
```

`gen:data` expects the repo root's `vite-node` (installed in the root package). It plays the exact first-card strategy used by `scripts/shots.mjs`, including the selected third card at round 1 pick 3, so the final scores match `game-over.png` (EN 45/39/38; ZH 47/36/33).

## Implementation rules followed

- **Remotion only.** Every animation is `useCurrentFrame()` + `interpolate()` or `spring()`. No CSS transitions, no CSS keyframes, no ffmpeg slideshow.
- **Real assets.** Screenshots are the same files in `docs/screenshots/`; card art is drawn in code; the demo JSON is generated by the pure engine; the poster is captured from the real app.
- **Media APIs.** `<Composition>` in `Root.tsx`; `<Sequence>` with `premountFor`; `<Img>` + `staticFile()`; `<Audio>` from `@remotion/media`.
- **Honesty.** The archival cut’s end card says “Web v0.1 · LAN and installer are next milestone”, which was true when it was rendered. The current app ships LAN and `video.json` includes it; no installer, 4K or online claim is made.

## Known limitations

- The 48.5 s cut is 1080p60; no 4K master is shipped in this pass.
- Voice is synthetic Edge TTS, not a human recording. It is intentionally −6% rate for a calm family tone.
- The music is a simple original synth bed, not a licensed track.
- No motion-blur or 3D; the design is deliberately paper/still-led.
- `docs/promo` contains both cuts and SRTs; no separate social vertical cut yet.
