# Glossary / 术语表

| English | 中文 | Meaning in this repo |
| --- | --- | --- |
| Sweet Carousel | 甜点转盘 | The game / repository. |
| Pick one, pass it on | 选一张，传下去 | The one-sentence promise used on the home screen, README and poster. |
| Round | 轮 | One deal of 8 cards per player. Three rounds make a game. |
| Pick | 选牌 | One card chosen from the current hand. |
| Hand | 手牌 | The private cards a player is choosing from. |
| Reveal | 翻牌 | The moment every seat's pick becomes public. |
| Pass left / pass right | 传左 / 传右 | Move the remaining hand to the next seat. Round 1 left, round 2 right, round 3 left. |
| Set | 同款组合 | Pair, triple or four-of-a-kind of one dessert. |
| Pair | 一对 | 2 copies = 2 points. |
| Triple | 三层 | 3 copies = 6 points. |
| Full plate | 满盘 | 4+ copies = 12 points; extras are leftovers. |
| Sampler | 拼盘 | Exactly three different leftover desserts = 5 points. |
| Leftover | 收尾甜点 | A card outside a set/sampler = 1 point each. |
| Crown / popularity crown | 人气王 | Final-only bonus: unique table leader with 6+ copies = 6 points. |
| Companion | 陪玩 | Gentle AI; avoids taking a human's last needed card when possible. |
| Easy | 轻松 | Low-depth AI with noise. |
| Normal | 标准 | Heuristic AI plus a short sampled rollout. |
| Hard | 挑战 | Heuristic AI plus a larger sampled rollout. |
| Hot-seat | 传设备 | 2–5 humans sharing one device, with a cover between hands. |
| Cover | 遮罩 | The “pass the device” privacy screen. |
| Autosave | 自动保存 | The current game is written to `localStorage` after each move. |
| Review | 回看本局 | The post-game round/pick recap. |
| FACTS | 事实清单 | The claims checked against the engine for the promo. |
