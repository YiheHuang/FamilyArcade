# Glossary / 术语表

| 中文 | English | 在本项目中的含义 |
| --- | --- | --- |
| 彩庭 | Hue Garden | 本游戏名；2–4 人、20–30 分钟的原创瓷砖拼放。 |
| 瓷砖 / 砖 | tile | 一张圆角釉面砖，由「色 × 形」确定，共 36 种组合、每种 3 张。 |
| 釉色 | glaze / colour | 六种颜色：陶土、赭黄、橄榄、海蓝、靛青、梅紫。 |
| 形状 | shape | 圆、菱、叶、星、滴、花；同时是色弱友好的第二通道。 |
| 色记 | colour seal | 每张砖右下角的字母（T/S/O/M/I/P），颜色之外的第二标记。 |
| 手牌 / 牌架 | rack / hand | 当前玩家手里的最多 6 张砖。 |
| 牌袋 | bag | 未发出的砖；UI 只显示数量。 |
| 庭院 | courtyard | 开放的方形网格棋盘；第一块砖在中心 `(0,0)`。 |
| 一条线 | line | 横向或纵向连续的一段砖；只共享一个属性。 |
| 开花 / 六连 | bloom / six-line | 一条线正好 6 张；计 6 分 + 6 分奖励。 |
| 换牌 | swap | 用 1–3 张手牌与牌袋交换；牌袋必须够。 |
| 跳过 | pass | 没有可铺线且牌袋为空时的唯一动作。 |
| 打空 | clear | 牌袋空后打空手牌，+6 并结束。 |
| 陪玩 | Companion | 四档 AI 之一；不故意堵人，有噪声。 |
| 轻松 / 标准 / 挑战 | Easy / Normal / Hard | 其余三档 AI；预算分别 80 / 300 / 900 ms。 |
| 热座 | hot-seat | 2–4 人共用一块屏幕轮流玩。 |
| 主机 / 客人 | host / guest | 局域网中主机保留完整牌局；客人只收到自己的视图并发送意图。 |
| 房间号 / 二维码 | room code / QR | 4 位房间号；二维码链接自带房间、码、名字。 |
| 重连 | reconnect | 客户端令牌回到原座位，主机重发 start/view。 |
| 复盘 | replay | 用同一引擎重新应用走法，不是录屏。 |
| 自动保存 | autosave | 每步写入 `localStorage`，刷新后继续。 |
| 提示 | hint | 用同一套 AI 给出建议 + 一句理由；不会替玩家走。 |
| 家庭房规 | house rule | 中心开局、只接两端、袋空才可跳过；见 `rules.md`。 |
