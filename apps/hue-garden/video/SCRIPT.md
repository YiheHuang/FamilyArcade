# Hue Garden promo — 50 s · 1920×1080 · 60 fps

A quiet, typographic film for the family tile-laying game **彩庭 / Hue Garden**.
Paper, glazed courtyard tiles, a real 38-turn engine game, and two narration cuts
(Chinese and English) on the same timeline.

- **Duration** 50.0 s · 3000 frames per cut
- **Format** 1920×1080, 60 fps, H.264/AAC, yuv420p
- **Cuts** `HueGardenPromoZH` (中文) and `HueGardenPromoEN` (English), both rendered
  to `../docs/promo/`
- **Built with** Remotion 4 (`video/`), real engine data, real app screenshots
- **Accuracy** every claim is checked by [`FACTS.md`](FACTS.md); the film makes no
  LAN, installer or desktop claim.

## Design language

- Paper `#f7f1e5`, ink `#24303a`, brass accent `#b08a4f`, rule `#d9cbb6`
- Six glazes and six shapes are imported from `src/ui/theme.ts`; tiles are drawn
  in code, never copied from a publisher
- Type: serif headlines (Iowan/Palatino/Noto Serif SC/Songti), sans body
  (Avenir/Segoe/Noto Sans SC/Microsoft YaHei)
- Motion is only `useCurrentFrame()` + `interpolate()`; no CSS transitions or
  keyframes. Scenes are `<Sequence>` elements with `premountFor`.

## Audio

- **Score** — 50 s original ambient bed generated by `scripts/gen-audio.mjs`
  (sine chords, slow tremolo, no third-party music).
- **Narration** — seven lines per language generated by `scripts/gen-voice.mjs`.
- **SFX** — tile tick, placement, tick, closing chime, all synthesized in
  `scripts/gen-audio.mjs`.
- **Subtitles** — burned in from `src/data/narration.{zh,en}.json`; SRT sidecars
  are written to `../docs/promo/hue-garden-promo-{zh,en}.srt`.
- **Master** — `scripts/master.mjs` applies the measured +gain and a real
  `alimiter` (not just a volume knob), then re-encodes AAC and writes
  `../docs/promo/audio-check.json`. Final measurements: Chinese **−14.37 LUFS /
  −1.80 dBTP**, English **−14.11 LUFS / −1.90 dBTP** (target −14 ±1, TP ≤ −1).

## Build

```bash
cd video
npm install
npm run gen        # real engine data + audio + voice + SRT
npm run facts      # accuracy gate -> FACTS.md
npx remotion studio
npm run render     # out/hue-garden-promo-zh.mp4
npm run render:en  # out/hue-garden-promo-en.mp4
npm run master     # +gain, limiter, AAC master + audio-check.json
```

The app screenshots are produced by `../scripts/shots.mjs` from the real Vite app
with Playwright and system Chrome. Copy them into `video/public/shots/{en,zh}` before
rendering. Poster stills are generated with `npm run stills` and copied to
`../docs/promo/`.

## FACTS list

The checked claims below are generated into [`FACTS.md`](FACTS.md):

- 108 tiles = 6 colours × 6 shapes × 3 copies; 18 per colour and 18 per shape.
- Hand of 6; play 1–3 tiles; a line of 6 scores 6 + 6 (bloom); empty-rack +6.
- 2–4 players; four AI levels (Companion / Easy / Normal / Hard).
- The 38-turn game is generated by the real engine and replayed by `replay()`.
- All desktop stills are 1440×1000, phone still 780×1688, captured from the app.
- 50 s, 1920×1080, 60 fps; seven non-overlapping narration lines in each language.
- No LAN, installer or desktop claim is made in this cut.

## Why each claim is true

- `src/game/tiles.ts`, `data/tiles.json` and `tests/data.test.ts` define the tile set.
- `src/game/engine.ts` owns legal lines, scoring, blooms and endings; `video/scripts/gen-data.ts`
  replays the exact move list and exports snapshots.
- `scripts/shots.mjs` captures the real app at fixed viewports; `video/public/shots/`
  contains those exact PNGs.
- `video/scripts/facts.ts` fails the build if any of the above drifts.
