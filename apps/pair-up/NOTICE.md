# NOTICE · Pair Up / 翻牌记忆

Pair Up is an original, non-commercial family game made for Family Arcade. The
memory-pair mechanic is a public-domain folk game; this implementation, its name,
copy, visual design and code are original.

- No third-party art, card text, font files or audio samples are included.
- The card backs, layout, player colours and icons are drawn in CSS for this project.
- Tile faces use the operating system's emoji font; no emoji image files are bundled.
- Sound effects are synthesised at runtime with the Web Audio API.
