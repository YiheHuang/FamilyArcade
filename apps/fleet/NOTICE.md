# NOTICE · Fleet / 海战棋

Fleet is an original, non-commercial family game made for Family Arcade. The hidden-fleet
battleship mechanic is a public-domain folk game; this implementation, its name, copy,
visual design, code and sound design are original to this project.

- No third-party art, card text, font files, music or audio samples are included.
- Every ship, chart, marker and icon is drawn in CSS/SVG by this app.
- Sound effects are synthesised in the browser with the Web Audio API.
- QR codes are generated locally by the `qrcode` npm package (MIT). No QR image is
  downloaded or embedded from a remote service.
- The app uses the Family Arcade shared LAN package and Tauri LAN relay shell. No other
  game's assets or code are copied.

  owners.
